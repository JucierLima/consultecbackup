# Consultec Tecnologia
Site estático em HTML, CSS e JavaScript, responsivo para computador e celular.

## Configurar WhatsApp
Abra `js/script.js` e troque `SEU_NUMERO_AQUI` pelo número oficial, somente números e com código do país. Exemplo de formato: `5581999999999`.
