# Consultec Tecnologia — Vercel

Site estático pronto para publicar na Vercel.

## Publicar
1. Acesse https://vercel.com/new.
2. Importe este projeto ou envie a pasta extraída.
3. Se solicitado, escolha Framework Preset: Other; Build Command: vazio; Output Directory: vazio (raiz do projeto).
4. Clique em Deploy.

## WhatsApp
Antes de publicar, abra `index.html` e substitua `SEU_NUMERO_AQUI` pelo número oficial, no formato `55DDDNÚMERO` (somente dígitos).

## Arquivos
- `index.html`: site completo.
- `assets/logo-consultec.png`: logo.
- `datacentecerconsultec2.jpg`: imagem principal.
